# S12 — Оптимизация расходов на AI (черновик)

Бот и инструменты разработки тратят меньше на Gemini при том же качестве ответов.

> Черновик, заведён 2026-11-18 на приёмке S10: за время разработки на Gemini API ушло около $0.50,
> в основном прогоны `eval:ai` (оценка, разбивку по моделям не смотрели). Объём не согласован.

## 1. Цель и границы

- **Входит:** видимость расходов и снижение их в боте и в скриптах проверки.
- **Не входит:** смена провайдера LLM без отдельного решения.

## 2. Что делаем

Кандидаты, не решения:

- **Скрипты проверки:** кэш эмбеддингов мок-базы для `eval:rag` (ключ — хэш текста); `eval:ai` по фильтру
  в обычной работе, полный прогон — перед приёмкой.
- **Агент:** число раундов tools и размер контекста на раунд (промпт, схемы tools, история); кэширование
  контекста Gemini.
- **Учёт:** расход эмбеддингов (индексация, поиск) в статистике AI — сейчас считаются только ходы агента
  и голос.

## 3. Инварианты, которые этот спринт обязан удержать

- Качество: `eval:ai` и `eval:rag` не хуже последнего прогона S10.
- Правила S09/S10 («не выдумывать», аллергены, стоп-лист) не ослабляются ради экономии токенов.
