```

```

## 2026-10-12 — Спеки S02 и S03
**Цель:** написать спеки S02 (информация и меню) и S03 (бронь и обращения) перед стартом.
**Решения:** S02 — миграций нет, поиск по названию заменяет подсказку на свободный текст, скрытые блюда фильтруются в SQL (защита от подделки `callback_data`). S03 — состояние сценария в `conversations.state` с `draftId`, идемпотентность через `idempotency_key` (двойной тап = два разных `update_id`), уведомление менеджера только при `created = true`, одна миграция (`manager_chat_id`, `manager_notified_at`).
**Осталось:** таблицу спринтов в `roadmap/README.md` обновить при закрытии (ссылки на S02/S03).
**Ответы на вопросы §4 (2026-10-12):** S03 время — кнопки «Обед/Ужин», затем часы каждый час; остальное по рекомендациям (колонка `manager_chat_id`, без проверки по часам работы, контакт опционален для отзывов, интеграционный тест идемпотентности). S02 — по рекомендациям (новое сообщение на шаг, блюда без категории только через поиск, без фото, без алиасов).
