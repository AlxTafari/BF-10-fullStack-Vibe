# S01 — Данные и каркас бота

После спринта гость пишет боту `/start`, получает приветствие и кнопки главного меню, а диалог и сообщения сохраняются в Supabase. AI в боте нет (ADR-004).

## 1. Цель и границы

- **Входит:** проект Supabase, миграции схемы (MVP-план §4), seed (ресторан, FAQ, 5–10 блюд), webhook Edge Function с проверкой секрета, сохранение `conversations`/`messages`, `/start` и главное меню на inline-кнопках (разделы пока заглушки), ответ на произвольный текст — подсказка выбрать пункт меню.
- **Не входит:** меню и поиск блюд (S02), бронь/обращения (S03), админка (S04+), RLS-политики для менеджера (S04).

## 2. Что делаем

### 2.А Схема / данные
- Миграции: `restaurants`, `faq_entries`, `menu_categories`, `menu_items`, `conversations`, `messages`, `booking_requests`, `guest_requests` (последние две — пустые, схема сразу, чтобы не плодить миграции).
- `conversations.state` (jsonb) — задел под машину состояний сценариев S03.
- `restaurant_id` во всех данных ресторана; неизвестные значения — `null`, не ноль.
- Индексы под будущую курсорную пагинацию: `messages (conversation_id, created_at desc, id desc)`.
- RLS включён везде; доступ из функций через service role.
- `seed.sql`: 1 ресторан, несколько FAQ, 5–10 блюд.

### 2.Б Сервер
- `supabase/functions/telegram-webhook` + `_shared` по слоям 03-урока: `domain/`, `repositories/`, `telegram/`, `handlers/`.
- Проверка `X-Telegram-Bot-Api-Secret-Token`.
- Upsert диалога по идентификатору Telegram, запись входящих и исходящих сообщений.
- Идемпотентность по `update_id` (задел под дедупликацию S03).
- Роутер: команды, callback-запросы, произвольный текст → подсказка с меню.
- Сервис `getRestaurantInfo` (читает `restaurants`) — первый сервис ядра, сигнатура под будущий tool-calling.

### 2.В Экран
Экрана нет — «экран» = чат в Telegram.

## 3. Инварианты

- Бот не выдумывает данные; без данных говорит «нет данных, уточните у персонала».
- Внутренние данные ресторана гостю недоступны.
- Повторная доставка того же `update_id` не дублирует сообщения.

## 5. Что показываем на приёмке

1. Написать боту `/start` → приветствие ресторана и кнопки меню.
2. Нажать «О ресторане» → адрес и часы из `restaurants`.
3. Написать произвольный текст → подсказка выбрать пункт меню.
4. В БД: `conversations` и `messages` содержат обе стороны диалога, повторный update не создаёт дубль.
