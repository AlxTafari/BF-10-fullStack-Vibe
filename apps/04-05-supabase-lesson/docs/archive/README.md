# Архив

Здесь лежит закрытое: журнал завершённых спринтов (`log/`, плоско, имя файла = имя спринта) и отработавшие архитектурные документы (`architecture/`). Текст записей перенесён сюда **дословно** из корневого `LOG.md` — ничего не
переписывалось и не сокращалось.

**QA хранится только локально.** Корневой `QA.md` и `qa/` в `.gitignore` и в репозиторий не попадают; на закрытии спринта `QA.md` переносится в локальный `qa/<спринт>.md`.

**Читать целиком не нужно.** Чтобы понять, что построено и где мы стоим, есть [`../STATE.md`](../STATE.md).
Сюда идут за причиной конкретного решения.

Активные файлы — в корне репозитория: [`/LOG.md`](../../LOG.md) и [`/QA.md`](../../QA.md), в них
живёт только текущий незакрытый спринт. Спринт закрыт — его записи целиком переезжают сюда.

## Ритуал закрытия спринта

Только после явного «да» пользователя на приёмке. Ни прогон, ни ревью, ни зелёные тесты сами по
себе спринт не закрывают.

1. Архив — файлы с именем спринта, как у спеки (`S01-data-and-webhook`): весь `LOG.md` →
   `docs/archive/log/S01-data-and-webhook.md`, дословно, без сокращений. Локально, без коммита: весь `QA.md` → `docs/archive/qa/S01-data-and-webhook.md`.
2. В таблицу ниже — строка-указатель для `log/` (`qa/` в git нет, указателя не требуется).
3. `docs/STATE.md` — обновить: сданный спринт в §1, что построено в §2, новые расхождения с ADR в §3,
   новые хвосты в §4.
4. ADR, затронутые спринтом, — сменить статус («Отложено» → «Принято, реализовано <спринт>»).
5. Корневые `LOG.md` / `QA.md` — после переноса в архив сбросить к пустому шаблону (заголовок + формат записи). Копии в корне не остаются: содержимое живёт только в архиве.
