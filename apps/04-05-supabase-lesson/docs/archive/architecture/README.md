# Архив архитектурных документов

Сюда переезжает отработавшее: решённые гипотезы, выполненные планы миграций, черновики, которые
привели к ADR. Файлы не удаляются — они объясняют, почему решение именно такое.

Правило переноса: документ теряет статус «действующий» → в шапку добавляется строка
`**Архивирован:** 2026-10-12 — <причина, ссылка на итог>` → файл `mv` сюда → ссылки в других
документах правятся на новый путь.
