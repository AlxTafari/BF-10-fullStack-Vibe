## 2026-10-12 — Спеки S02 и S03
**Цель:** написать спеки S02 (информация и меню) и S03 (бронь и обращения) перед стартом.
**Решения:** S02 — миграций нет, поиск по названию заменяет подсказку на свободный текст, скрытые блюда фильтруются в SQL (защита от подделки `callback_data`). S03 — состояние сценария в `conversations.state` с `draftId`, идемпотентность через `idempotency_key` (двойной тап = два разных `update_id`), уведомление менеджера только при `created = true`, одна миграция (`manager_chat_id`, `manager_notified_at`).
**Осталось:** таблицу спринтов в `roadmap/README.md` обновить при закрытии (ссылки на S02/S03).
**Ответы на вопросы §4 (2026-10-12):** S03 время — кнопки «Обед/Ужин», затем часы каждый час; остальное по рекомендациям (колонка `manager_chat_id`, без проверки по часам работы, контакт опционален для отзывов, интеграционный тест идемпотентности). S02 — по рекомендациям (новое сообщение на шаг, блюда без категории только через поиск, без фото, без алиасов).

## 2026-10-12 — S02: реализация
**Цель:** FAQ, меню (категории → блюда → карточка), поиск блюда по названию.
**Решения:** `toLikePattern` вынесен отдельно от `normalizeSearchQuery` (репозиторий не импортирует домен, получает готовый шаблон). Лимиты: поиск по тексту — 8, блюда категории — 30 (`CATEGORY_ITEMS_LIMIT`; восемь для категории мало). Кнопки «Главное меню» → `menu:main`; битый/подделанный `callback_data` → тихо главное меню. Репозитории и сервисы прогнаны по dev-БД read-only скриптом: скрытая «Рыба дня» не находится, Cyrillic `ilike` без учёта регистра работает, `У 0` показывается.
**Осталось:** задеплоить функцию (`pnpm functions:deploy`) и пройти приёмку §5 спеки S02 в Telegram; закрытие спринта после «да».

## 2026-10-13 — S02: правки после проверки, тексты бота, приёмка
**Цель:** убрать лишнее из S02, выяснить, где живут тексты интерфейса, принять и закрыть спринт.
**Решения:** `CATEGORY_ITEMS_LIMIT` 30 → 10 (30 кнопок в чате много, в меню 4–5 блюд на категорию); при превышении — подсказка искать по названию (`CATEGORY_TRUNCATED`). Тексты бота живут в двух местах осознанно: реплики и кнопки — `content.ts`, подписи полей данных — домен (форматтеры; домен не импортирует `content.ts`, ADR-008). Единый словарь `strings` не вводим до второго языка. Правило оформить ADR-009 при закрытии. Функция задеплоена в dev; пользователь принял спринт («закрываем спринт»).
**Осталось:** хвосты в STATE §4; S03 — по спеке.
